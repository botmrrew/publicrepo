# Public Repo

Uma aplicação web moderna com HTML, CSS e JavaScript.

## 🚀 Como acessar

Este projeto está hospedado no GitHub Pages em:
- **URL**: https://botmrrew.github.io/publicrepo/

## 📁 Estrutura

- `index.html` - Página principal
- `styles.css` - Estilos da aplicação
- `app.js` - Lógica da aplicação
- `config.js` - Configurações

## 💻 Desenvolvimento

Para trabalhar localmente, clone o repositório:

```bash
git clone https://github.com/botmrrew/publicrepo.git
cd publicrepo
```

Abra o arquivo `index.html` no seu navegador ou use um servidor local:

```bash
# Com Python 3
python -m http.server 8000

# Com Node.js (se instalado)
npx http-server
```
